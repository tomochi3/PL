# 都道府県ページの記録データ

## 3つの表示

| 表示 | 集計 | 対象 |
| --- | --- | --- |
| 新人大会・最高 | 性別・階級ごとの最大Total | 東京・愛知の都県大会、近畿の地区大会 |
| 県大会・最高 | 性別・階級ごとの最大Total | 既存の `prefecture-fallback-results.js` |
| 国スポ・ボーダー | 性別・階級ごとの最小Total | 2026年国スポの最終選考通過者の予選記録 |

「全階級」は選択中の性別の全階級を集計する。男女は混ぜない。データがない階級に全階級の数値を代入しない。新人・県大会は収録した直近大会の記録であり、歴代日本記録ではない。

新人大会の対象は、JPAに登録し、公式戦への出場経験がない選手。参加条件の詳細は大会要項による。通常の県大会に付属する新人区分（元データの兵庫県など）を、独立した新人大会の表示に混ぜない。近畿の最高Totalは地区全体の値として保持し、滋賀・京都・大阪・兵庫・奈良・和歌山の各府県に複製しない。

県大会の既存データは47都道府県それぞれ男子最高記録1件だけで、女子・他階級は未収録。山形・鳥取の合同／地区大会や一部記録会を含む。選択UIを全モードで共通化し、この収録範囲を画面に明記している。

## 国スポの「ボーダー」の定義

出場に必要な固定kg数ではなく、**本戦の最終選考を通過した選手の予選Totalの最低値（実績）**を目安として示す。県大会の優勝者や最大Totalを、そのまま国スポ代表と扱わない。補欠・予選参加者・本戦での記録・自己ベスト・失格は集計しない。

[2026年JPA公式開催要項・選考方法](https://ros-cms-data.s3.ap-northeast-1.amazonaws.com/_file/10951/9ecb8b386b.pdf)では、各県の男子2名・女子1名（開催県は男子4名・女子2名）を階級順位とIPFポイントで選考する。このため表示Totalを超えても出場を保証しない。選手名、階級、IPFポイント、予選結果と通過者発表へのリンクを一覧で確認できる。

`kokuspoMetadata.edition` と同年かつ `qualificationStatus: "qualified"` の、有限で正のTotalだけを集計する。`verifiedSelections` は代表全員を照合できた性別を表す。その範囲で記録がない階級は「該当階級の通過者なし」、未調査・選考結果が不明な範囲は「未確認」と表示する。どちらも0kgにしない。

### 原資料の表記差異

- 長野県：PDF上部の年表記は2025年だが、末尾の日付は2026年4月19日。2026年の国スポ選考結果として収録し、`heldAt` は末尾の2026-04-19を採用。既存の県大会モードのデータは変更していない。
- 福岡県：JPAが第55回の結果として掲載するPDFのヘッダーは「第54回・2025年10月18日」のまま。県協会の2026年選考発表にある氏名・階級・IPFポイントとPDFの数値が一致することを照合した。大会名・日付は発表にある第55回・2026年4月18日を採用。別年度の一般参加者を推測で代表に採用しない。

## 追加・更新方法

1. 対象年度の公式予選結果と、最終代表／選考通過者の発表を確認する。PDFは文字抽出だけでなく表の列・丸印・脚注も目視確認する。
2. 氏名・階級・Total・IPFポイントを照合して `kokuspo-results.js` に行を追加する。`sourceUrl` は予選結果、`selectionSourceUrl` は通過者の根拠を指す。同一資料で両方確認できる場合は同じURLでよい。
3. その性別の全代表を確認した場合だけ `verifiedSelections` に性別を追加する。部分的な確認では、他階級を「通過者なし」と判定しない。
4. 年度を更新するときは `edition`、開催地の説明、選考方法リンク、確認範囲をあわせて見直す。`heldAt` は予選日、`asOf` は確認日。旧年度を混ぜない。
5. `node --test tests/records.test.cjs` と `node --check prefectures.js` を実行。ブラウザーで3モード、男女、全階級と個別階級、地域・県名絞り込み、数字表示、モバイル幅を確認する。
